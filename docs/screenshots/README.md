The desktop images show the top 1200 px of each page. The phone images show the top 1400 px.

The images show placeholder content only. Recapture them after a change to the design, the header, or the layout of a page.

## How to recapture

1. Build and preview the site:

   ```bash
   npm run build
   npm run preview
   ```

2. Open each page listed above in a browser at the width shown in the table. In Chrome, open the developer tools and use the device toolbar to set the width.
3. Turn on reduced motion (Rendering panel, "Emulate CSS prefers-reduced-motion"), so the entrance animations are finished before you capture.
4. Save a screenshot of the area described above, and replace the file of the same name.
